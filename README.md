# 阶段证据目录

本目录按文献检索与筛选阶段组织，可独立阅读，所有文件引用均指向包内材料。

**04 阶段待确定。** 当前已暂存 113 份 PDF；最终纳入名单、数量及人工交叉验证结果尚未确定。

## 目录结构

- `01_六库检索与去重`
  - `01_查询命中950`：六库查询命中汇总、逐条查询明细、检索词与范围及结果截图。
  - `02_库内唯一393`：库内去重后的 393 条记录及去重依据。
  - `03_跨库唯一253`：跨库去重后的 253 条记录及归并依据。
- `02_TAK初筛`：253 篇的初筛结果汇总及通过初筛的 117 篇清单。
- `03_滚雪球`：冻结六库检索后追加的滚雪球阶段，列示 18 篇补充候选文献，并汇总 135 篇候选文献的现有 PDF。
- `04_人工交叉验证与最终纳入`：**待确定**。其中的“最终论文清单”文件夹目前用于暂存论文，目录名称不代表最终纳入结果已确认。

## 阅读说明

六库查询命中阶段从 `01_六库检索与去重/01_查询命中950/950条查询命中证据.xlsx` 开始阅读。工作簿包含“命中汇总”“查询明细”“检索词与范围”三张表，截图位于同目录的“截图”文件夹。

库内去重阶段从 `01_六库检索与去重/02_库内唯一393/393条库内唯一记录证据.xlsx` 开始阅读。工作簿包含“去重汇总”和“论文清单”两张表。393 条记录保留库间重复，跨库去重在下一阶段处理。

跨库去重阶段从 `01_六库检索与去重/03_跨库唯一253/253条跨库唯一记录证据.xlsx` 开始阅读。工作簿包含“去重汇总”“唯一记录清单”和“归并明细”三张表，展示 393 条记录归并为 253 条的对应关系。

TAK 初筛阶段从 `02_TAK初筛/TAK初筛-117篇.xlsx` 开始阅读。工作簿包含“筛选汇总”和“初筛清单”两张表。汇总展示 253 篇中保留 117 篇、排除 136 篇的结果；初筛清单仅列出通过的 117 篇，包含主记录 ID、论文标题、来源数据库、初筛结论和文献链接。

滚雪球阶段从 `03_滚雪球/18篇滚雪球补充文献清单.xlsx` 开始阅读。清单根据现有流程记录整理旧清单回补 17 篇及后续补录 1 篇，包含补充编号、论文标题、年份和文献链接；最终纳入结果在后续复核阶段确定。

`03_滚雪球/135（117+18）篇候选文献` 文件夹已归档 134 篇 PDF，文件名以 MU 或 SB 编号对应前述清单。尚缺 1 篇的下载入口列在同目录的 `待下载文献清单.xlsx` 中。MU-0184 与 MU-0232 归档的是已确认对应的早期题名版本。

`04_人工交叉验证与最终纳入/最终论文清单` 文件夹现暂存 113 份 PDF，保留原始文件名。该阶段的人工交叉验证记录、最终纳入名单及数量均待确定。
